The hole in the middle

Every assistant today makes you pick one of two things. We wanted both.

Cloud assistants

They can remember you, but the memory sits on someone else's computer. It has no structure, it cannot say where a fact came from, and you cannot correct it. You can only delete everything and start again.

Phone assistants

They are private, but they do not know you. Every request starts from nothing. Ask about a project you have worked on for a month and it has never heard of it.

What we built

A structured model of your world that builds itself from what you allow, explains where every fact came from, takes your correction as final, and never leaves the phone unless you send it somewhere yourself.

Choosing the brain

Three open models, the same 150 tests, the same settings, the same runtime. Only the model changed.

Qwen3 14B scored highest. We did not choose it. A 14 billion parameter model does not fit in an iPhone's memory next to a speech model and a voice model, so it was never a real option. The question that mattered was which model small enough for a phone does best, and Nemotron 4B beat Phi 4 Mini at almost the same size.

The Qwen run is still useful. It measures the gap between what fits in your pocket today and what a bigger machine can do.

These are automatic checks, not human judgement, and one run per model. Enough to see a clear difference. Not enough to argue about small gaps. Full method and raw files: model comparison.

Why the memory can be trusted

Most apps store facts in a table. A table cannot tell you who said so, or when, or what the old answer was. So we store statements, and every statement carries how much authority it has.

5You corrected meBeats everything. The old version is kept, marked as ended.
4You told meYour own words, in conversation.
3A trusted source said itA document you shared.
2I observed itYour calendar, your reminders. Never outranks your own words.
1I worked it outA guess. Stored as a question, not a fact, until you say yes.

A lower number never overwrites a higher one. So your calendar cannot quietly move a meeting you told it about, and a guess never becomes a fact on its own. Nothing is destroyed by a correction, which is why the app can always answer the question why do you think that?

Real bugs that only testing found

  • It could agree with itself. The app asked "should I send it?", the microphone heard its own voice, and the words could count as a yes.
  • Silence sounded like a word. The speech model invents words in silence, and one of them is "okay", which is an agreement.
  • Email was impossible because of one example. An old line in the prompt taught the model to say it cannot send email. No new instruction could beat it.
  • The prompt grew too large and broke every request. Caught only because we ran the real model before shipping.

Where it falls short

Written down because a project record that only lists wins is not a record.

  • The thinking step takes about 1.3 seconds on an iPhone 15 Pro against a target of 0.75. The chip produces about 77 tokens a second for this model, so this is the hardware, not the code.
  • The full 3,249 case run has not been completed on the phone. Samples have.
  • The connected services have never been tested against a live account. They are tested against recorded responses, which is not the same thing.
  • Speech recognition struggles when the assistant is talking and there is no echo cancellation. One test is marked as a known failure for this.
  • The model comparison is one run per model, scored automatically, on cases that were visible during development.
